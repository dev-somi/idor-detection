# 0004. 판정-근거 불일치 지표와 반복 일치 지표 추가, 보조 모델 실행

- 날짜: 2026-10-24
- 상태: 채택

## 맥락
본 실험(`runs/20261024-153314_qwen2.5-7b`)의 응답 원문을 확인했다. verdict는 vulnerable인데 `missing_context`에 누락된 함수를 적은 응답이 있었다(case_10 C, case_12 B/C/D 등). 정답과 같은 판정이지만 근거가 틀린 응답도 있었다(case_09 B). 3회 반복의 판정은 모두 같았다.

## 결정
- `evaluate.py`에 두 지표를 추가한다. 정답표를 다시 보지 않고 예측 기록만으로 계산되며, 실험을 다시 실행하지 않는다.
  - `decided_with_missing_context`: 확정 판정(vulnerable/no_issue_found)인데 missing_context가 비어 있지 않은 횟수
  - `cases_consistent_across_repeats`: 모든 반복에서 판정이 같은 사례 수
- 반복 판정이 모두 같으면 탐지 지표의 n=36은 독립 표본 36개가 아니다. 사례 12개의 3배일 뿐이라는 점을 summary에 명시한다.
- qwen3:8b(Q4_K_M, `think:false`)로 같은 설정과 프롬프트를 써서 보조 실행한다. 주 결과는 qwen2.5:7b이다.

## 결과
- 프롬프트와 예제는 바꾸지 않았다(프롬프트 v1 유지).
- 근거 원문 검토는 일부만 사람이 했다. 체계적인 근거 정확성 평가는 다음 단계 과제다.
