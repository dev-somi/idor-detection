# 0001. 초기 설계와 모델 선택

- 날짜: 2026-10-24
- 상태: 채택

## 맥락
팀 회의까지 약 5시간 남은 시점에 구현 코드가 없었다. 장비는 Apple M5, RAM 16GB, macOS 26.5.1, Python 3.11.15이다. Ollama가 설치되어 있고 qwen2.5:7b, qwen3:8b, llama3.2 3B, qwen3.5:2b 모델이 로컬에 있다.

## 결정
- 주 모델은 `qwen2.5:7b`(Q4_K_M)로 한다. thinking 모드가 없어 출력 제어가 단순하고 추가 다운로드가 필요 없다. `qwen3:8b`는 시간이 남으면 보조로만 실행한다.
- 생성 설정은 temperature 0, seed 42, num_ctx 16384, num_predict 768, JSON 스키마 출력으로 고정하고 A~D 모든 조건에 똑같이 적용한다.
- 외부 의존성 없이 표준 라이브러리(ast, urllib, unittest)만 쓴다. pytest가 설치되어 있지 않아서 unittest를 사용한다.
- 추출은 모듈 최상위 함수와 `이름(...)` 형태의 직접 호출만 지원한다. 속성·메서드 호출, import, 데코레이터, 동적 호출은 "미해석"으로 표시하고 따라가지 않는다.
- 예제는 자체 제작 12개다. 정답은 `ground_truth/labels.json`에 분리해 두고, 예측 코드는 이 파일을 읽지 않는다.
- 판단 불가(insufficient_context)는 주 지표의 혼동행렬에서 제외하고 판단 가능 비율을 따로 보고한다. 보조 지표로 판단 불가를 양성(사람 검토 필요)으로 본 값도 함께 보고한다.

## 결과
- 작은 자체 제작 예제에서 얻은 결과이므로 실제 프로젝트로 일반화하지 않는다.
