# 0002. 예제 코드(cases/*/app.py)는 주석 규칙에서 제외

- 날짜: 2026-10-24
- 상태: 채택

## 맥락
프로젝트 지침은 "모든 코드에 어떤 코드인지 주석을 단다"로 정했다. 그런데 `cases/*/app.py`는 그대로 LLM 입력이 된다. 연구 요구사항은 "정답과 취약 여부를 드러내는 파일명·함수명·주석은 모델 입력에 포함하지 않는다"이다.

## 결정
- 도구 코드(`idor_ctx/`, `tests/`)에는 주석 규칙을 적용한다.
- `cases/*/app.py`에는 주석과 docstring을 넣지 않는다. 사례 설명, 정답, 이유는 `ground_truth/labels.json`에만 둔다.

## 결과
- 모델 입력에 정답 힌트가 들어갈 위험이 줄어든다. `tests/test_leakage.py`로 예제 파일에 주석이 없는지와 금지어가 없는지를 검사한다.
